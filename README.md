# ❤️ 心动挑战（Heart Dare）

一个简洁优雅的情侣互动小游戏，采用单文件 HTML 实现，无需安装、无需服务器，打开即可游玩。

## ✨ 功能特色

- 🎲 猜拳决定输赢
- 🩷 随机决定 S / M 身份
- 🎲 动作 + 部位双随机骰子
- 🎨 多套主题配色可切换
- 🌏 中英文双语支持
- ✏️ 自定义动作和部位
- 📱 响应式设计，支持手机和电脑
- 🚀 纯 HTML + CSS + JavaScript，无任何依赖

## 🎮 游戏玩法

1. 双方先进行一局猜拳。
2. 输的一方点击 **GO**。
3. 系统随机决定本局身份（S 或 M）。
4. 点击 **摇骰子**。
5. 根据随机生成的动作和部位完成挑战。
